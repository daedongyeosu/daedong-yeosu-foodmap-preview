개인정보처리방침

대동여수음식지도는 필요한 정보만 최소한으로 사용하고, 위치정보를 사용자가 기대하는 서비스 기능에 한정해 처리합니다.

시행일 2026년 7월 29일
회원가입 없음서비스 이용을 위해 이름·전화번호 로그인을 요구하지 않습니다.
위치 선택 가능현재 위치를 거부해도 주소 검색과 지도 선택을 사용할 수 있습니다.
정확한 주소 비공개관리자 통계에는 동 단위 또는 여수 외 지역처럼 대략적인 지역만 표시합니다.

2. 처리하는 정보와 이용 목적

구분처리하는 정보이용 목적보관 기준
현재 위치 사용자가 위치 버튼을 누르고 허용한 경우의 기기 위치 가까운 음식점 표시, 거리 계산, 지도 위치 맞춤 해당 기능을 제공하는 동안만 사용하며 정확한 좌표를 운영 통계에 저장하지 않습니다.
기기 내 저장 정보 선택한 배달 위치, 찜한 가게, 최근 방문 가게 등 다음 방문 때 사용자의 설정과 목록을 다시 보여주기 브라우저 또는 앱의 저장공간에 보관되며 사용자가 데이터·캐시를 삭제하거나 초기화할 때까지 유지될 수 있습니다.
익명 이용 통계 페이지 방문, 가게 열람, 주문경로 버튼 클릭, 가게 QR·공유 링크 유입, 날짜, 대략적인 지역 구분 가게별 이용 현황 확인, 서비스 개선, 홍보 효과 측정 수집일로부터 최대 12개월 보관한 뒤 삭제하거나 개인을 식별할 수 없는 집계 정보로 전환합니다.
기술 정보 접속 시 자동 생성될 수 있는 IP 주소, 브라우저·기기 종류, 접속 시각, 오류 기록 서비스 제공, 보안, 장애 확인 서비스 제공업체의 보안·운영 정책 및 관계 법령에 필요한 기간 동안 보관될 수 있습니다.

관리자 통계에는 사용자의 정확한 좌표나 상세 주소를 표시하지 않습니다. 여수시 안에서는 동 단위, 여수시 밖에서는 시·군·구 또는 “여수 외 지역”처럼 대략적인 지역 구분만 사용합니다. 운영자 자신의 확인용 접속은 가능한 범위에서 통계에서 제외합니다.

3. 위치 권한 사용

  • 위치정보는 사용자가 현재 위치 기능을 직접 선택했을 때 전면에서만 요청합니다.
  • 서비스는 백그라운드에서 지속적으로 위치를 추적하지 않습니다.
  • 사용자는 위치 권한을 허용하지 않아도 주소 검색, 저장된 주소 선택, 지도에서 위치 지정 기능을 이용할 수 있습니다.
  • Android 설정 또는 브라우저의 사이트 설정에서 언제든 위치 권한을 변경하거나 철회할 수 있습니다.
  • 위치정보는 광고 목적으로 판매하지 않습니다.

4. 외부 서비스와 정보 공유

서비스는 음식점의 주문 방법과 지도 정보를 한곳에서 찾도록 돕기 위해 먹깨비, 땡겨요, 배달의민족, 쿠팡이츠, 요기요, 온동네, 브랜드 앱, 전화, 지도 등 외부 서비스로 연결될 수 있습니다.

  • 사용자가 외부 링크를 누르면 해당 업체의 앱 또는 웹사이트로 이동하며, 이동한 뒤의 정보 처리는 해당 업체의 개인정보처리방침이 적용됩니다.
  • 해당 가게 또는 주문 화면을 열기 위해 가게 식별값이나 유입경로 같은 링크 정보가 외부 서비스에 전달될 수 있습니다.
  • 서비스는 개인정보를 판매하지 않으며, 법령상 의무가 있거나 사용자가 별도로 동의한 경우를 제외하고 개인을 식별할 수 있는 정보를 제3자에게 제공하지 않습니다.
  • 웹사이트 제공 과정에서 GitHub Pages 등 호스팅·인프라 제공업체가 기술적 접속 기록을 처리할 수 있습니다.

5. 보유 기간과 파기

개인정보는 이용 목적을 달성하면 지체 없이 삭제하거나 복구하기 어려운 방법으로 파기합니다. 관계 법령에서 일정 기간 보관을 요구하는 경우에는 해당 기간 동안 분리해 보관할 수 있습니다.

  • 기기 내 저장 정보: 사용자가 앱 데이터·브라우저 저장정보를 삭제하거나 기능을 초기화할 때 삭제
  • 익명 클릭·유입·대략적 지역 통계: 수집일로부터 최대 12개월 후 삭제 또는 비식별 집계
  • 문의 과정에서 사용자가 제공한 연락정보와 내용: 문의 처리 완료 후 3개월 이내 삭제(분쟁 대응 또는 법령상 보관 의무가 있는 경우 제외)

6. 사용자의 권리와 선택

  • 위치 권한을 허용하거나 거부하고, 나중에 철회할 수 있습니다.
  • 브라우저 또는 Android 설정에서 저장정보·캐시를 삭제할 수 있습니다.
  • 본인과 관련된 정보의 열람, 정정, 삭제 또는 처리 정지를 요청할 수 있습니다.
  • 익명 통계는 이름·전화번호 같은 식별정보와 연결하지 않으므로 특정 개인의 기록을 찾아 삭제하기 어려울 수 있습니다.

권리 행사는 아래 이메일로 요청해 주세요. 본인 확인이 필요한 경우 필요한 범위에서 확인 절차를 진행할 수 있습니다.

7. 안전성 확보 조치

서비스는 전송구간 암호화(HTTPS), 접근 권한 제한, 정확한 위치정보의 통계 저장 방지, 관리자용 정보와 공개 정보의 분리 등 합리적인 보호조치를 적용합니다. 다만 인터넷을 통한 전송과 저장 방식은 절대적인 안전을 보장할 수 없으므로, 문제가 확인되면 영향을 줄이기 위한 조치를 신속히 진행합니다.

8. 서비스 성격과 상표 안내

대동여수음식지도는 여수시 또는 배달의민족, 쿠팡이츠, 요기요, 먹깨비, 땡겨요 등 외부 주문 플랫폼의 공식 서비스나 후원 서비스가 아닙니다. 주문계약, 결제, 취소, 환불, 배달 및 상품 관련 책임은 실제 가게와 해당 주문 플랫폼의 정책에 따릅니다. 각 회사명·서비스명·상표의 권리는 해당 권리자에게 있습니다.
