# 위치 약관과 동의 화면 정비

## 확인한 문제와 수정 범위

2026년 11월 3일 공개 화면과 최신 preview 소스를 확인했다. 홈에는 개인정보처리방침만 있었고, 위치 약관 원본의 시행일이 비어 있었다. 기기 위치 권한을 요청하기 전 서비스의 별도 동의 절차가 없었다. GPS 좌표의 외부 역지오코딩과 기기 내 장기 보관도 있었다.

- `location-privacy.js`: 약관 전문 링크, 미리 선택하지 않은 동의, 만 14세 이상 확인, 약관 버전별 재동의, 기록 확인과 철회. 기기의 위치 권한과 서비스 동의를 분리한다. 기록 저장이 실패하면 GPS를 서비스에 적용하지 않는다.
- `app.js`, `rc6-fixes.js`, `rc7-address-map.js`: 현재 위치를 요청하는 세 경로 모두 공통 동의를 거친다. GPS는 방문 화면과 탭의 임시 저장공간에만 보관하고 주소록에는 넣지 않는다. 기존 GPS 기록을 정리하며 수동 주소·찜은 보존한다. 철회 뒤 늦게 돌아온 위치 응답은 적용하지 않는다.
- `rc7-address-map.js`: GPS 역지오코딩과 자동 외부 지도 이동을 제거한다. GPS로 얻은 지역 정보는 일반 이용 통계에도 보내지 않고 기기에 남은 전송 대기분의 GPS 지역도 비운다. 주소 선택 뒤 자동 외부 지오코딩도 제거한다. 선택형 외부 지도는 안내를 확인하고 직접 불러온다. 여수 외 GPS 접속자의 구체적인 시·군·구는 추정하지 않는다.
- `/location-terms/`: 기존 28개 조항과 부칙을 보존한 전문을 공개한다. 목적·보유기간·권리행사와 사업자 연락처를 보강한다.
- `/privacy/`: 별도 위치 동의, 기기 좌표 보관, 서버 확인자료 6개월 보관, 철회와 삭제를 설명한다. 이전 방침은 `/privacy/20260729.html`에 보존한다.
- 홈과 마이페이지에 약관과 위치 동의 관리 경로를 둔다. 서비스워커 캐시를 새 버전으로 갱신한다. 과거 기능 검사의 캐시 버전 기대값만 함께 갱신한다.

가게 데이터, 순서, 전화번호, 메뉴, 사진, 주문·지도 링크는 변경하지 않는다. 실제 주문·라이더 추적·위치의 제3자 제공을 새로 허용하는 변경이 아니다.

## 시행일과 배포 순서

현재 수정안의 기준일과 약관 버전은 **2026-11-03 / 2026-11-03.1**이다. 이는 미배포 검토본이다. 기존 10월 26일 파일은 시행일이 빈 원안으로 보존한다. 검토본을 이미 공개한 약관으로 보고하지 않는다.

실제 공개일이 11월 3일과 달라지면 배포 전에 다음을 같은 날짜·버전으로 갱신한다. 과거 날짜로 소급하지 않는다.

1. `location-terms/terms.json`, `location-terms/index.html`, `privacy/index.html`
2. `location-privacy.js`의 VERSION, 비공개 API `LOCATION_VERSION`
3. 별도 보관 중인 약관 개정안 DOCX와 시행 기록

preview PR 병합·배포는 사용자 명시적 승인 후 진행한다. 운영 도메인 반영은 별도 승인 대상이다. 먼저 비공개 API의 D1 마이그레이션과 기록 보관·만료 삭제를 적용하고, 승인한 환경에서만 `LOCATION_JOURNAL_ENABLED=true`를 설정한다. 기록 API가 준비되기 전에 화면만 배포하지 않는다.

preview에서 실제 동의 저장, GPS 이용 시 기록, 본인 기록 조회, 철회 후 삭제, 재동의, 네트워크 장애 때 주소 이용, 만료 삭제를 확인한다. 운영 배포 때는 운영 API 주소·허용 origin과 별도 데이터베이스도 확인한다. 약관의 원본 DOCX와 공개 전문의 문장이 일치하는지 확인한다.

## 운영 확인

정확한 좌표를 기록하지 않아도 동의·이용 확인자료와 접속 기록은 보호 대상이다. 활성화 전 실제 Cloudflare 처리 위탁·국외 처리 조건, 저장 위치, 운영자 접근권한을 확인하여 처리방침에 실제 계약 조건을 반영해야 한다. 외부 지도 제공업체의 공개 정책만으로 개별 서비스의 위탁계약·국외이전 요건을 충족했다고 단정하지 않는다. 수동 지도 표시도 별도 제공 범위가 확정되기 전에는 GPS를 전달하지 않는 구성을 유지한다.

위치정보 취급·관리지침, 접근권한 부여·변경 이력, 연 1회 자체점검과 교육 기록은 실제 수행일에 기록한다. 이번 소스 검사를 과거 운영 조치까지 수행한 증거로 쓰지 않는다.
