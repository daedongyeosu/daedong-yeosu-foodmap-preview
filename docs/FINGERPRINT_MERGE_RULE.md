# 주문앱 지문등록식 누적 보완 원칙

주문앱 링크나 사진이 들어오면 가게별 고유 기록에 다음 항목을 한 묶음으로 검사한다.

1. 가게 식별: 주소 우선, 전화번호는 달라도 같은 주소면 같은 가게로 판단 가능
2. 가게명·주소·좌표
3. 전화번호: 땡겨요 → 먹깨비 → 주소가 일치하는 네이버지도 순서
4. 주문링크
5. 대표사진·가게사진
6. 메뉴명·설명·메뉴사진
7. 영업시간·휴무일
8. 주문앱별 쿠폰
9. 주문앱별 상품권·결제수단
10. 주문앱별 무료배달
11. 네이버지도: 긴 주문앱 지점명을 그대로 검색하지 않고 핵심 상호명으로 넓게 검색한다. 후보의 지번·도로명 주소를 수집된 사업자 주소와 우선 대조하고 전화·업종·좌표로 보조 확인한 뒤 같은 실제 영업장일 때만 연결한다. 지점명·괄호·띄어쓰기 불일치나 첫 검색 무결과는 `장소 없음`의 근거가 아니다. 샵인샵 미등록이면 미제공한다.

기존 정상 데이터는 삭제하거나 덮어쓰지 않고 빈 항목과 추가 확인값만 병합한다.
요기요·쿠팡이츠·배달의민족 전화번호는 사용하지 않는다.
혜택은 모든 주문앱 공통으로 표시하지 않고 확인된 주문앱 이름과 함께 표시한다.
