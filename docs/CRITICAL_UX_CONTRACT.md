# 대동여수음식지도 핵심 UX 고정 계약

이 문서는 관련 없는 작업으로 고객 기능이 사라지거나 되돌아가는 것을 막기 위한 보존 기준이다.

## 배포 경계

- 모든 수정은 preview에서 먼저 검증한다.
- preview 승인만으로 운영 `daedongmap.com`을 변경하지 않는다.
- 사용자의 최종 승인 전에는 운영 저장소에 병합하거나 운영 배포하지 않는다.

## 메인 화면

- 메인 슬라이드는 비어 있는 영역으로 남지 않아야 한다.
- 메인 슬라이드의 좌우 화살표는 광고를 가리지 않도록 숨긴다.
- 가게 슬라이드에는 영업 중 또는 곧 종료 가게만 표시한다.
- `둔덕동의 가게` 같은 위치 라벨은 표시하지 않는다.
- 가게명과 `미평, 둔덕 · 한식` 같은 실제 지역·카테고리 정보는 보존한다.
- `여수 소상공인 소식`, `여수 힐링요트`, `오마카세 우미` 광고와 노션 연결을 보존한다.

## 뒤로가기

- 카카오톡의 일반 루트 링크로 새로 들어오면 과거 주문앱 복귀 기록이 남아 있어도 홈 최상단에서 시작한다.
- 주문앱 출발 때 발급한 현재 화면의 일회용 URL 또는 history 표식이 저장된 복귀 상태와 일치할 때만 보던 위치를 복원한다.
- 먹깨비·땡겨요·요기요·쿠팡이츠·배달의민족 등 주문앱에서 돌아오면 홈 화면을 먼저 보여주지 않는다.
- 보던 가게와 가게 내부 스크롤 위치를 가능한 즉시 복원한다.
- 노션 광고에서 돌아오면 네트워크 재로딩을 기다리지 않고 보던 슬라이드를 즉시 표시한다.
- 복귀 중 행사 팝업이나 앱 설치 유도 화면을 반복해서 띄우지 않는다.

## 가게와 주문방법

- 기존 가게 ID, 이름, 순서, 사진, 좌표, 전화번호, 주문·지도 링크를 요청 없이 변경하지 않는다.
- 가게 상세에는 해당 가게에 실제 존재하는 주문방법만 표시한다.
- 다른 주문방법 보기에는 요기요·쿠팡이츠·배달의민족만 표시하고 기본 주문방법과 중복하지 않는다.
- 전화번호 우선순위는 땡겨요 → 먹깨비 → 네이버지도 원본 순서를 유지한다.
- 네이버지도는 검증된 원본 링크가 없으면 추정하여 만들지 않는다.

## 위치·검색·영업상태

- 검색은 좌표 유무와 무관하게 정상 가게 전체를 대상으로 한다.
- 고객 위치·저장 주소·선택 동네를 기준으로 해당 지역 가게를 우선 표시한다.
- 영업상태 정렬은 영업 중 → 곧 종료 → 시간 미확인 → 영업종료 순서를 유지한다.
- 전체 가게 수, 영업종료 수 등 민감한 내부 집계는 고객 화면에 표시하지 않는다.
- 홈 빠른 찾기의 `지금 영업 중` 숫자는 전체 가게 수가 아니라 고객의 현재 선택을 돕는 실시간 정보이므로 표시한다. 로딩 중에는 `확인 중`, 확인 실패 시에는 `다시 확인`을 표시하며 잘못된 `0`을 먼저 노출하지 않는다.

## 여수섬섬페이

- 고객 문구는 `여수섬섬페이 가맹점`으로 통일한다.
- 대동여수음식지도 내부에서 `섬섬페이 사용가능 확인` 같은 불필요하게 긴 표현을 되살리지 않는다.
- 먹깨비·땡겨요 양쪽 적용이 확인된 경우 두 주문앱 모두에 동일하게 반영한다.

## 먹깨비 행사 팝업

- 모바일 한 화면에서 행사 내용과 주문 버튼, 오늘 하루 보지 않기를 모두 볼 수 있어야 한다.
- 닫기 버튼은 48×48px 터치 영역과 주황색 테두리를 유지한다.
- 닫기 버튼 옆 장식용 원형 음영을 다시 만들지 않는다.
- 팝업 닫기와 오늘 하루 보지 않기 동작을 보존한다.

## 시각·데이터 보존

- 승인된 여수 바다·돌산대교·거북선 배경을 관련 없는 작업에서 변경하지 않는다.
- 광고 한 개를 수정하면서 다른 광고를 삭제하지 않는다.
- 가게 한 곳을 수정하면서 다른 가게의 링크·사진·메뉴·혜택을 변경하지 않는다.
- 내부 검수 문구, 데이터 집계, 출처·검증일을 고객 화면에 노출하지 않는다.
