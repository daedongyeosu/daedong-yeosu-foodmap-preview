# 자동수집 대조 가게 전용 지도

## 범위

사용자 요청은 자동수집 완료 원본과 운영지도 등록 가게를 대조하고, 사업자번호·주소가 같은 복수 브랜드 후보의 가게별 전용 지도와 여백 없는 QR을 준비하는 것이다. 사용자가 명시적으로 제외한 가맹점 엑셀과 온동네 목록은 이 작업의 기준으로 사용하지 않는다.

신규 전용 화면 252개는 `data/collected-campaign-stores.json`에 명시된 기존 등록 가게만 대상으로 한다. 기존 22개 캠페인, 가게 등록 원본, 주문 링크, 좌표, 노출 우선순위, 숨김 설정은 바꾸지 않는다. 사업자번호와 원본 경로는 공개 저장소에 포함하지 않는다. 원본이 같은 다른 수집 폴더를 별도 가게로 세지 않는다. 자동 대조는 샵인샵 운영 사실이나 현재 계약관계에 대한 법적 확인이 아니다.

## 화면 및 QR

- 새 전용 주소는 기존 `https://daedongmap.com/?hero=<storeId>` 규칙을 사용한다. 기존 사이트의 동일 ID 상세와 주문방법을 재사용한다.
- 사진이 있는 가게는 해당 가게의 기존 대표 사진 1장을 사용한다. 사진이 없는 43개는 안내 배경과 가게명으로 표시한다. 다른 가게 사진을 빌려 쓰거나 메뉴사진 14장이 확보됐다고 주장하지 않는다.
- 기존 공통 안내 3개는 유지한다. 기존 승인 캠페인의 여러 장 사진 구성은 그대로 둔다.
- QR은 M 오류복원, 바깥 여백 0모듈이다. 인쇄 배치에는 주변의 깨끗한 흰 공간이 필요하므로 QR 바로 옆에 글자·그림을 붙이지 않는다. PNG는 비공개 작업공간에서 생성하고 실제 운영 진입 확인 후에만 사용자 완성품 폴더에 저장한다.
- 새 SVG QR은 `assets/qr/collected-<storeId>.svg`이다. 사용자가 쓰는 PNG는 한국어 가게명으로 저장한다.

## 검증 및 배포 경계

- `collected-shopinshop-campaign-regression-test.mjs`: 대상 252개 명시, 기존 캠페인/가상 가게/링크의 내용 해시 보존, 다른 가게 배너 혼입 방지, QR 테두리 0 검증.
- 기존 전체 회귀검사와 정적·데이터·공개 저장소 감사 수행.
- 390×844 Chromium에서 로컬 후보 파일을 운영 도메인에 덮어 읽는 미리보기 검사. 운영 배포 검증과 구분한다. 전체 새 캠페인 구성 및 252개 이미지 로드를 검사하고 대표 진입 4회에서 상세 열기·닫힘 유지를 검사한다.
- 공개 Preview 및 메인 병합·배포는 별도 승인 전 수행하지 않는다. 새 QR을 배포 완료품으로 넘기지 않는다.
