# 심부름·즉시배송 국내외 운영 조사와 적용 기준

작성일: 2026-10-11  
적용 대상: 여수맛지도 `가져오기 → 전달하기` 심부름 1차 서비스

## 결론

심부름 서비스는 모든 사례를 한 화면에 나열하는 방식으로 운영하지 않는다. 고객이 물품과 작업을 설명하면 시스템이 위험요소를 분류하고 필요한 질문만 추가로 제시해야 한다. 모든 요청은 다음 네 경로 중 하나로 끝나야 한다.

1. 일반 접수
2. 특별취급 접수
3. 운영자 검토·별도견적
4. 접수불가

현재 프리뷰는 실제 결제·젠딜리 전송을 계속 잠근 상태에서 이 분기와 주문 증빙부터 구현한다.

## 국내 기준에서 확인한 운영 원칙

### 운송장과 물품가액

- 찾기쉬운 생활법령정보는 운송장의 물품명과 물품가격이 분실·파손 시 보상범위 판단 근거라고 설명한다.
- 가액을 기재하지 않은 택배의 표준 손해배상한도는 50만원이며, 가액별 할증운임을 낸 경우에는 해당 구간의 최고가액이 적용될 수 있다.
- 퀵서비스 사업자의 귀책으로 배송이 예정시간의 50% 이상 지연되면 배송비용 환급 기준이 있고, 특정 시각 사용 물품의 지연에는 별도 기준이 있다.

적용:

- 주문서에 물품명·수량·가액·포장상태를 필수 구조화한다.
- 가격으로 환산하기 어려운 서류·열쇠는 별도 선택을 허용하되 자동 확정하지 않고 검토 대상으로 보낸다.
- 시간 민감 물품은 사용 예정시간과 지연 가능성을 별도로 확인한다.

### 고가물과 책임

- 상법은 화폐·유가증권 등 고가물의 종류와 가액을 송하인이 명시한 경우를 책임 판단의 중요한 조건으로 둔다.
- 약관으로 사업자의 고의·중과실 책임까지 일괄 배제할 수는 없다.

적용:

- 고객 체크 한 번으로 모든 파손 책임을 고객에게 넘기지 않는다.
- 픽업 전 상태, 포장 상태, 기사 인수 판단, 적재 방법, 사고 발생 시점의 증빙을 함께 보관한다.
- 실제 보상한도와 보험 범위는 운송·배상책임보험 및 법률 검토 후 확정한다.

## 여수맛지도 1차 접수 규칙

### 일반 접수

- 밀봉된 소형 생활물품
- 일반 의류와 포장된 상품
- 가액이 확인되고 대체 가능한 물품

필수 정보: 물품명·수량, 규모, 포장상태, 물품가액, 출발·도착 공식주소, 연락처.

### 특별취급

- 케이크·꽃·유리·도자기·만년필
- 액체·국물·잉크
- 노트북·태블릿·카메라 등 전자기기
- 냉장·냉동 또는 정해진 시각에 필요한 물품

추가 확인: 충격·눌림 방지, 이중 밀봉, 기존 상태 사진, 완충 포장, 보냉 한계, 시간 지연 가능성. 파손·전자기기·고가품은 사진 없이는 다음 단계로 진행하지 않는다.

### 운영자 검토·별도견적

- 50만원 이상 물품
- 정확한 가액을 산정하기 어려운 물품
- 큰 짐·여러 박스 또는 오토바이 적재 가능 여부가 불명확한 물품
- 포장이 적합한지 고객이 판단하지 못하는 물품

이 경로는 결제를 바로 열지 않고 차량·포장·보험 가능 여부와 요금을 확인한 뒤 고객 재승인을 받는다.

### 접수불가

- 현금·수표·유가증권·귀금속·결제수단
- 불법 물품·장물·무기·폭발성·인화성·독성 물질
- 사람·살아 있는 동물
- 안전 포장으로도 누출·파손 위험을 통제하기 어려운 물품
- 현 단계의 담배·주류

## 주문 상태와 사고 처리

고객 주문:

`작성 중 → 위험판정 → 견적대기 → 결제대기 → 결제확인 → 배차요청`

기사 수행:

`배차수락 → 픽업도착 → 포장검수 → 인수완료 → 배송중 → 수령확인 → 완료`

예외:

`수정요청 / 추가결제대기 / 부분환불대기 / 픽업거절 / 고객부재 / 반송중 / 사고접수 / 정산보류`

사고접수 시 주문·기사 정산을 잠그고 픽업 사진, 기존 상태, 포장확인, GPS·시간, 인계 증빙, 고객·기사 진술을 같은 사건번호에 보존한다.

## 구현 단계

### 이번 단계

- 고객 물품가액·포장상태 입력
- 키워드와 고객 선택을 결합한 위험 분류
- 물품별 동적 안전 질문
- 사진 필수 조건
- 일반·특별취급·운영자검토·접수불가 분기
- 주문 데이터에 위험등급·위험표시·확인기록 포함

### 다음 단계

1. 관리자 접수함에 위험등급·포장·가액·확인기록 표시
2. 기사 픽업 검수·거절사유·전후 사진
3. 수령 PIN 또는 서명·사진
4. 고객 주문 수정 → 재견적 → 차액 결제·부분환불
5. 다중 경유지와 경유지별 인계 물품
6. 부재·대기·반송·사고·정산보류 상태
7. 보험사·법률 검토를 반영한 보상한도와 최종 약관

해외 서비스의 금액·중량·보상한도를 그대로 복사하지 않는다. 여수의 오토바이 운송환경, 기사 장비, 보험계약과 국내 법률에 맞춰 별도로 확정한다.
