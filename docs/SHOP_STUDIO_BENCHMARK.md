# 맛지도 상점 꾸미기 비교 분석과 적용 기준

확인일: 2026-10-16. 공식 사용 설명서와 제품 소개를 읽고 비교했다. 타사 유료 편집기를 실제 조작하거나 소스코드를 분석한 것으로 표현하지 않는다. 성능·매출 효과를 검증한 자료가 아니다.

## 구현 경계

- 현재 편집기는 사진 최대 40개를 사용하는 평면 진열 시안이다. 구역은 하나의 진열장을 나누는 것이며 실제 방·통로·3D 이동을 구현한 것은 아니다.
- 내부 좌표와 화면 비율을 4:3으로 유지해 기기 폭에 따라 물건과 선반의 상대 위치가 달라지는 문제를 줄인다. 회전된 사진의 모서리까지 고려해 공간 밖으로 벗어나지 않게 한다.
- 투명 사진은 투명 여백만 잘라 물건의 아래쪽이 선반에 맞도록 처리한다. 원본 파일은 바꾸지 않는다. 완전히 투명한 이미지는 오류로 안내한다. 불투명 배경을 자동으로 지우는 AI 배경 제거와는 다르다.
- 위치 잠금은 이동·크기·회전·삭제를 막는다. 이름·숨김·그림자·겹침 순서는 계속 수정할 수 있다. 복제물은 잠금과 숨김을 해제한 상태로 만든다.
- 숨김은 이 배치 시안에서 고객 미리보기까지 숨기는 기능이다. 판매 상품을 품절시키거나 실제 판매를 중지하는 기능과 다르다.
- 저장은 현재 브라우저의 IndexedDB에 사진과 배치 하나를 저장한다. 계정별 저장·다중 매장·기기 간 동기화·백업은 미구현이다.
- 자동 배경 제거·AI 착장·AI 인테리어·상품원장·가격·재고·주문접수·결제·배송은 이 편집기와 아직 연결되지 않았다. 현재 지원하는 구매 연결은 사장님이 직접 등록한 가게·상품 주문 링크로 이동하는 기능이다.

## 매장 방문과 배달 주문 연결 (2026-10-16 추가)

- 사장님이 실제 주소·영업시간·전화번호·지도 공유 링크·가게 주문 링크·배달/포장 안내를 작성한다. 이 정보도 기존 기기 내 시안과 함께 저장한다.
- 고객 미리보기 상단에 방문·주문·전화 동작을 보여준다. 등록하지 않았거나 형식이 잘못된 링크는 연결 준비 중으로 표시하고 활성 링크를 만들지 않는다. 지도 링크는 사장님이 제공한 네이버/카카오지도 HTTPS 링크를 사용하며 주소로 장소 ID를 추측하지 않는다. 해당 장소와 실제 가게의 일치 여부를 자동 검증한 것은 아니다.
- 진열한 사진에 상품 설명과 개별 주문 링크를 붙인다. 개별 링크가 비어 있으면 '가게 주문 화면 열기'로 안내하고, 개별 링크가 있으면 해당 주소를 그대로 사용한다. 가격·옵션·재고·배송비·도착 예상은 연결된 주문 화면에서 확인하도록 안내한다.
- 실제 매장 사진은 '사장님이 꾸민 온라인 공간'과 구분해 표시한다. 고객 공개나 계정별 서버 저장은 아직 없다.
- 테스트는 임시 브라우저 컨텍스트와 가상의 테스트 주문 페이지로 수행한다. 실제 상점 전화·실제 주문·결제를 실행하지 않는다.
- 방문 링크 클릭을 실제 방문, 주문 링크 클릭을 주문 완료로 간주하지 않는다. 실적 측정은 향후 실제 주문원장과 구분해 설계한다.

## 다음 검증 순서

1. 실제 사장님이 안내 없이 사진 선택 → 진열 → 수정 → 되돌리기 → 재방문을 수행하게 하고 막힌 지점을 기록한다.
2. 실제 커피·빵·철물·의류 원본사진에서 배경 제거의 정확도와 수정 작업량을 시험한다. 톱니·손잡이 구멍·투명 유리는 별도 확인한다.
3. 시안 속 물건과 실제 상품 ID를 연결한다. 복수 진열과 단일 재고를 구분하고 편집이 판매원장을 변경하지 않도록 한다.
4. 작은 매장에서 먼저 검증한 뒤 공간 계층과 자산 불러오기 방식을 확장한다. 수백 진열대·수만 상품을 현재 40사진 구조에 그대로 넣지 않는다.
5. 실제 기기·사진 수별 초기 표시시간, 드래그 반응, 메모리, 저장 실패율을 측정한다. 성능 수치 없이 대형 매장 지원을 약속하지 않는다.
