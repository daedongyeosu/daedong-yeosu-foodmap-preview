# 이웃 중고장터 구매자 동선 개선

## 작업 계약

- 대상: preview 이웃 중고장터의 진열면 탐색, 사진 확대, 상세 확인, 체험 장바구니 담기·빼기.
- 보존: 저장된 사진·확대용 사진·가격·상품 ID·배치·배경·진열대·소품·휴지통·저장 revision. 기존 상점, 홈, 운영·관리자·젠딜리·수집기 코드와 데이터는 변경하지 않는다.
- 실제 구매·예약·결제·배송·배차는 연결하지 않는다. 예약 작업도 만들지 않는다.
- 사용자 승인: 검사 통과 후 preview에만 병합·배포. 성공한 정확한 PR head를 확인한 뒤 병합하고, Pages 및 배포 후 검사를 별도로 확인한다.

## 변경 전 확인

390×844의 격리된 브라우저에 시험용 3개 진열면을 준비했다. 아래 상품 목록은 모든 면의 상품을 섞어 보여주지만 상품·상세·장바구니에 원래 면 표시가 없었다. 장바구니에서 상세를 다시 열 수 없고, 계속 구경하기는 원래 진열판 대신 아래 전체 상품 목록으로 이동했다. 빈 면에서도 구매자에게 사진 추가·상품 이동을 안내했다.

사진만 확대하는 기존 뷰어는 정상이다. 해당 뷰어·편집기·저장 모델은 수정하지 않는다. 실제 휴대전화나 공개 판매 서비스 실증으로 표현하지 않는다.

## 구현 소유권

- `neighbor-market/market.js`: 면별 목록 필터와 출처 표시, 장바구니 사진·상품 상세 재확인, 장바구니에서만 빼기 안내, 원래 진열판/목록으로 돌아가기. 면 탐색 시 필터도 동기화하고 다른 장터로 바꾸면 이전 복귀 표식을 지운다.
- `neighbor-market/index.html`: 이름이 있는 필터, 빈 목록 안내, 상세의 면 표시와 명시적인 닫기 버튼. JS/CSS 캐시 버전 갱신.
- `neighbor-market/market.css`: 좁은 화면의 필터·장바구니 사진/긴 이름/상세·빼기 버튼 배치. 빼기 버튼 64px와 터치 높이 44px 유지. 장바구니 배경을 불투명하게 해 뒤의 사진·가격과 겹쳐 읽히지 않게 한다.
- 저장 구조, 사진 처리, 확대·핀치·끌기, 판매 상태, 실제 주문 경로는 변경하지 않는다. 각 중고 물건은 1점이며 판매완료·중복 담기 차단도 유지한다.

## 검증

- 새 `neighbor-market-buyer-faces-regression-test.mjs`는 면 출처·필터 동기화·복귀 소유권·장바구니 재확인·서버 쓰기 금지를 검사한다.
- 새 `scripts/browser-neighbor-market-buyer-faces.mjs`는 기존 CI 브라우저 검사에서 실행한다. 수정 전에는 필터 부재로 실제 실패했다.
- 390×844, 320×568, 1280×900에서 다중 면·빈 면·전체/면별 목록·긴 이름/설명·판매완료·무료 나눔·면 간 장바구니 합계·개별 빼기·빈 장바구니·원래 상품 복귀를 확인한다.
- 실제 CDP 터치 핀치로 사진만 확대하고 페이지 배율은 그대로인지, 전체 사진 복원·닫기 후 상세/장바구니가 보존되는지 확인한다.
- 모든 구매자 조작 전후 IndexedDB 저장 레코드 전체를 대조한다. 시험은 독립 브라우저의 합성 자료만 쓰며 외부 요청/서버 쓰기를 차단한다.
- 기존 구매자 검사의 일반 `button` 선택은 새 상세 버튼과 구분되도록 `.basket-remove`로 명확히 한다. 기존 금액·독립 삭제·초점·64px·줄바꿈 금지·보존 판정은 줄이지 않는다.

이 문서는 구현/검증 범위를 설명한다. PR 검사·병합·실제 preview 배포 완료의 근거는 해당 PR과 배포 실행 결과를 확인해야 한다.
