# 처음 사용하는 상점주: 사진 → 진열 → 저장

## 작업 계약

- 문제: 모바일에서 여러 사진을 추가한 직후 마지막 사진의 상세 설정으로 이동했다. 다른 사진의 이름을 정리하는 길과 진열 정리·저장 경로가 불분명했다. 기존 ‘저장’ 바로가기는 기기 저장 확인 대신 계정·서버·공개 설정으로 이동했다.
- 변경 범위: preview 저장소의 상점 꾸미기 HTML/CSS/JS, 해당 회귀·브라우저 검사와 CI 실행 항목.
- 변경 금지: 메인사이트, 관리자 서버, 주문·결제·배차, 기존 상점 데이터·사진·링크, 기존 꾸미기 도구와 시안 형식.
- 완료 조건: 새 모바일 브라우저에서 사진 3장을 고르고 이름 입력 → 진열·드래그 → 기기 저장 → 파일 보관 → 다시 열기를 수행한다. 저장 실패는 성공으로 표시하지 않는다.

## 실제로 확인하고 수정한 지점

1. 업로드 후 사진 목록에 머물며 작은 사진 옆에서 표시 이름을 연속 입력한다. Enter/휴대폰 ‘다음’은 다음 사진으로 이동하고 마지막은 진열 단계로 이어진다. 한글 조합 중 Enter는 이동으로 처리하지 않는다. 이름 수정은 기존 되돌리기·저장 경로를 사용한다.
2. 주요 작업 세 개(사진 추가, 진열하기, 저장·공개 안내)를 메뉴 맨 앞에 둔다. 320px에서도 세 개를 옆으로 넘기지 않고 볼 수 있다. 가구·분위기·상품 연결 등 세부 도구는 그대로 남긴다.
3. 진열 단계에서 기존 자동 정리 도구를 바로 제공한다. 사용자가 눌렀을 때만 재배치한다. 잠김·숨김·가구 연결 사진은 보호하며 한 번 되돌리기로 복구한다. 기존 배치·파일 메뉴에서도 진열 정리로 이동할 수 있다.
4. 저장 단계는 실제 IndexedDB 트랜잭션 완료/실패를 표시한다. 기기 저장, 사진 포함 시안 파일, 고객 미리보기, 계정·고객 공개 안내를 분리했다. 기기 저장만으로 다른 기기·고객에게 보인다고 안내하지 않는다. 자동 서버 연결·공개·판매 등록은 추가하지 않았다.

## 검증

- AI 상점주 역할의 Chromium 모바일 브라우저 QA이며, 실제 사람 사용성 조사나 실제 휴대폰 키보드 검증은 아니다.
- 390×844, 320×844, PC 1280×900: 앨범 선택기·사진 3장·이름 연속 입력·한글 조합 방어·진열·한 번 되돌리기·기기 저장·JSON 파일 내용·재접속 복원을 확인했다.
- 모바일 CDP 터치 입력으로 사진을 실제 드래그하고 위치 변화/되돌리기를 확인했다. 상점은 계속 같은 화면에 유지된다.
- IndexedDB 쓰기 실패/사용 불가를 주입해 거짓 성공 표시가 없고, 마지막 정상 저장본과 파일 보관 경로가 유지되는지 확인했다. 잘못된 이미지와 정상 이미지를 섞은 업로드에서도 기존 사진을 보존한다.
- 잠금·숨김 사진, 가구에 연결한 사진이 자동 정리에서 바뀌지 않는다. 기존 사진 교체·상품등록 연결·48종 가구·베이커리 파일 내보내기/불러오기·체험 장바구니·한 화면 편집 검사도 유지한다.
- 새 브라우저 검사는 테스트용 loopback origin의 GET/HEAD만 허용한다. 외부 호출·서버 쓰기는 0건이다.
- 기존 HTML ID 283개를 모두 정확히 한 번씩 보존했다. 기존 release는 새 초보 경로 회귀검사에서 실패하는 음성 대조를 확인했다.
- 새 `shop-studio-first-owner-regression-test.mjs`는 표준 회귀 실행기에 자동 포함되며, `scripts/browser-shop-studio-first-owner.mjs`는 기존 CI의 격리 로컬 서버에서 실행한다.

## 남은 경계

- 실제 계정 저장·공개·다른 실제 휴대폰 표시와 판매 등록은 이 수정의 완료 주장에 포함하지 않는다. 이번 개선은 ‘기기 내 꾸미기 시안’의 사진·진열·저장 흐름이다.
- 실제 사장님이 처음 보고 도움 없이 완주하는지, Android/iPhone 키보드·사진 선택기 동작은 별도 실기기 확인이 필요하다.
- 기존 사용자 수정이 있던 `STORE_OWNER_EXPERIENCE_PLAN.md`는 변경·커밋하지 않았다.
- preview 병합·배포는 사용자 승인과 PR 필수 검사 성공 후에만 수행한다. 메인사이트·실결제·배차는 변경하지 않는다.
