## 화면과 분위기

- 종이 질감, 손때 묻은 나무 선반, 테이프로 붙인 간판, 작은 삼각 깃발, 종이 가격표를 사용한다. 낡은 카메라·책·캔버스백 AI 견본 사진을 새로 만들었다. 실제 판매 사진이나 감정·작동 확인 결과가 아니다. 생성 프롬프트/게시용 파일은 `assets/neighbor-market/README.md`에 기록했다.
- 첫 화면의 가상 장터 6개 물건과 내 장터를 분리한다. 이름·상태 설명은 선택이며, 사진과 원 단위 가격은 필요하다. 빈 가격은 오류, 명시적 0원은 무료 나눔이다.
- 내장 AI 견본으로 꾸미다가 내 사진 등록을 선택하면 AI 사진을 등록목록에 자동으로 끼워 넣지 않는다. 선택한 공간 스타일은 유지하고 내 사진으로 시작한다는 안내를 표시한다.
- 선택 도구: 분위기 4종, 벽/선반/간판 색, 표면 3종, 밝기, 가격표 표시, 장식 6종(최대 12개), 사진/장식 자유 이동·크기·잠금, 방향키·자동 정리·되돌리기/다시 하기. 실제 가격·물건 번호는 꾸미기로 바뀌지 않는다.
- 휴대폰은 공간 위/도구 아래, PC는 나란히 보인다. 긴 도구는 도구 안에서만 스크롤한다. 기존 상점의 도구를 복사·삭제하거나 그 저장공간을 이용하지 않는다.

## 저장·거래 경계

- 새 IndexedDB `matjido-neighbor-market-preview-v1`, `drafts/owner-draft` 한 곳만 사용한다. 기존 `matjido-shop-studio-v1/scene`, 실제 장바구니 원장, 상점 서버를 읽거나 쓰지 않는다.
- 사진은 브라우저에서 최대 640px WebP로 준비해 이 기기에 저장한다. 파일은 1장 15MB, 견본 장터는 20장 한도다. 서버로 업로드하지 않는다.
- 실제 IndexedDB readwrite 트랜잭션 완료 후에만 성공으로 표시한다. 읽기 불가·손상된 이전 저장본은 덮어쓰지 않는다. 다른 창의 더 최신 revision이 있으면 중단한다. 저장공간 오류 시 입력과 마지막 저장본을 유지하고, 명시적으로 ‘저장하지 않고 임시 미리보기’를 선택할 수 있다. 파일 보관은 별도 JSON 내려받기다.
- 체험 장바구니는 각 물건 1점이다. 같은 물건을 중복으로 담지 않는다. 판매완료 표시 체험 중인 물건은 담을 수 없고 기존 체험 장바구니에서도 제거한다. 이는 실제 재고 잠금·예약·판매완료 API가 아니다.
- 상품 합계만 표시하고 배송비는 미산정으로 둔다. 실제 개인 판매자 인증, 계정 간 공개/공유, 판매 신고, 결제·정산, 예약·거래 채팅, 배송·배차, 분쟁처리는 구현하지 않았다. 이름/사업자/매장 입력 없이 이 견본을 쓰는 것이 실제 판매 자격 확인을 대신하지 않는다.
- 실제 판매 상태로 공개하는 버튼·API는 없다. 모든 견본 화면에 실제 거래·결제·배송이 없음을 표시한다.

- 저장 전 닫기는 ‘저장하고 닫기 / 계속 꾸미기 / 저장하지 않고 둘러보기’를 구분한다. 저장하고 닫기는 실제 IndexedDB commit 후에만 닫는다. 실패하면 안내창과 현재 작업, 마지막 저장본을 유지한다. 저장하지 않고 둘러보기는 작업을 열린 화면에 유지하며 저장 완료라고 표시하지 않는다. 저장 후 닫기는 추가 확인 없이 끝낸다.
- 복원된 내 장터의 안내 링크는 ‘내 장터 보기’로 표시한다. 기기 저장/선택적 꾸미기와 고객 공개 전이라는 구분은 유지한다. DB 이름·저장 규격·원자적 revision 대조·사진 처리·거래 잠금은 바꾸지 않는다.
